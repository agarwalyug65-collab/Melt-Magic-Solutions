# Melt Magic Solutions — B2B Website

A responsive, lightweight B2B web interface for **Melt Magic Solutions**, a supplier of quality raw materials and refractory products for steel plants, foundries, and the metallurgical industry.

---

## 📌 Project Overview

This repository contains the front-end code for the official Melt Magic Solutions corporate landing page. The website is designed to showcase product offerings, highlight target industries, present core value propositions, and facilitate direct quote inquiries from B2B clients.

---

## 🛠️ Features

* **Responsive Navigation:** Clean sticky header with dynamic mobile toggle menu.
* **Hero & About Sections:** Introduces core supply capabilities and brand vision.
* **Product Catalog Grid:** Highlights key offerings:
  * Aluminium Oxide Powder
  * Refractory Products
  * Met Coke
  * Weld Mix Powder
* **Industry Overview:** Outlines key sectors served (Steel Plants, Foundries, Metallurgical Operations).
* **Interactive Contact Form:** Built-in form validation and submission feedback for quote requests.
* **Dynamic Content:** Automatically updates copyright year via JavaScript.
